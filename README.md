# MOBILE DATA USAGE AND INTERNET COST IN NIGERIA  
**Authors:** Akinbami Abosede Sera & Muhammed Isiwat Opeyemi

## Overview
This project analyzes mobile data usage patterns and internet costs in Nigeria using survey responses from 122 participants.

## Dataset
- **Source:** Google Form survey  
- **Sampling:** Simple random sampling  
- **Content:** Demographics, network provider, monthly data usage, monthly data cost, device type, and internet experience variables.

## Methodology
- **Design:** Quantitative survey  
- **Tools:** Excel, SPSS, Power BI  
- **Analysis:** Descriptive statistics and visualizations


## Summary of Findings
- Data costs are generally high for many users.  
- Usage varies by occupation, device type, and network provider.  
- Network quality significantly influences user satisfaction.
